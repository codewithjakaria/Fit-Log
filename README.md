# FitLog

FitLog is a workout library app where users can explore exercises, view workout details, build a daily workout plan, and save workouts for later.

## Live Demo

[Open FitLog](https://fit-log-pied-five.vercel.app)

## Features

- Browse workouts from the FitLog API.
- View each workout’s details, equipment, difficulty, sets, reps, duration, calories, rating, and instructions.
- Add workouts to today’s plan, with a maximum of five workouts.
- Save workouts to a separate list for later.
- View workout counts and plan statistics.
- Mark planned workouts as done or remove them from a list.
- Sort workouts by duration, calories, or rating.
- Keep plan and saved workout lists after refreshing the page.
